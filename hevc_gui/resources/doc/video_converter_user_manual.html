1. Introduzione

HEVC-Video Converter è un convertitore video open source pensato per rendere semplice e sicura la conversione in formato HEVC (H.265), mantenendo però strumenti avanzati (preview, filtri, audio, sottotitoli, capitoli, coda batch).

La GUI “nasconde” la complessità di FFmpeg ma ti lascia il controllo delle cose davvero importanti: qualità, preset, tracce audio, sottotitoli/capitoli e strumenti di verifica prima della conversione.

Novità principali (versione attuale):
  • Toolbar icon-only (pulsanti = icone PNG, stile LDVD).
  • Voce File → Riavvia… per riavvio “pulito” dell’app (reset stato in RAM).
  • Modulo integrato LDVD Ripper: DVD → file locale + (opzionale) OCR sottotitoli in SRT + handoff a HEVC.
  • Risorse icone Qt: path standard :/icons/... (generate durante il build del .deb).
Disclaimer: il software è fornito “così com’è”, senza garanzie. L’utente è responsabile di verificare la conformità alle leggi locali su copyright e codec.

2. Requisiti di Sistema

2.1 Sistemi operativi supportati

  • Linux (Mint/Ubuntu e derivate) — supporto principale.
  • macOS — supportato tramite script di build e dipendenze installabili.
  • Windows — possibile, ma alcune funzioni dipendono da tool esterni (setup più manuale).

2.2 Dipendenze software (comuni)

  • FFmpeg + FFprobe installati e raggiungibili dal PATH.
  • Python 3 + PyQt5 se usi la versione sorgente.
Test rapido (tutti i sistemi):

Se questi comandi non funzionano, HEVC non può convertire.

  • Tool DVD (a seconda del flusso LDVD): utilità per leggere titoli/capitoli/stream.

Workflow “a prova di dummy” (la sequenza migliore):
Apri → Preview → (Crop/Trim/Colore) → Preview filtrata → Converti
Se fai sempre così, riduci al minimo le sorprese.
Termine Spiegazione semplice
CRF Qualità “automatica”: tu scegli un numero (es. 20–24) e il bitrate si adatta. Più basso = più qualità = file più grande.
Bitrate Qualità “a budget”: tu scegli un numero (es. 2000k) e la qualità si adatta al limite. Utile se vuoi un peso più controllato.
Preset Velocità/efficienza: più lento = migliore compressione ma più tempo.

5. Come usare HEVC (conversione passo-passo)

5.1 Aprire un video (2 modi)

  1. Metodo 1: clicca Apri (icona in toolbar) e seleziona il file.
  2. Metodo 2: trascina il file video dentro l’app (se previsto dal tuo ambiente).

5.2 Prima verifica: Preview

Fallo sempre: la preview ti evita di convertire “il file sbagliato” o con audio/lingua non desiderata.

5.3 Scegliere qualità e preset (consigli pratici)

  • Se sei alle prime armi: usa CRF e un preset “medio” (es. medium/slow).
  • Se vuoi pesi simili tra episodi: usa bitrate (ma richiede più esperienza).
  • Non cambiare 10 cose insieme: fai una modifica, poi preview filtrata.

5.4 Se usi strumenti (crop/trim/colore): Preview filtrata

Regola salva-vita: dopo ogni tool (crop/trim/colore/aspect) fai Preview filtrata. Se l’immagine è deformata o tagliata, te ne accorgi subito.

5.5 Convertire

  1. Premi Converti.
  2. Attendi la fine e controlla l’output.
Metodo “anti-sorpresa” (consigliato): prima fai un test di 60–120 secondi (trim breve), poi lanci la conversione completa.

6. Ricette pronte (per chi vuole risultati subito)

6.1 “Ho un film con bande nere sopra/sotto”

  1. Apri il video.
  2. Apri Crop e ritaglia solo le bande nere (senza tagliare contenuto).
  3. Fai Preview filtrata.
  4. Converti.

6.2 “Voglio tagliare intro e titoli di coda”

  1. Apri Trim.
  2. Imposta inizio e fine (lascia un margine di sicurezza).
  3. Preview filtrata e converti.

6.3 “Audio 5.1: sento rumori ma non i dialoghi”

  1. Apri modulo Audio.
  2. Cambia profilo downmix o traccia audio.
  3. Fai test su 1–2 minuti con dialoghi evidenti.

6.4 “Ho un DVD e voglio anche i sottotitoli in SRT”

  1. Vai in LDVD Ripper e fai Estrai.
  2. Prova OCR SRT.
  3. Se l’OCR fallisce: usa Subtitle Edit (vedi sezione dedicata).
  4. Passa a HEVC e converti.

7. Strumenti Video (Crop / Trim / Colore / Aspetto)

7.1 Crop (ritaglio)

  • Serve a togliere bande nere e bordi inutili.
  • Se ci sono sottotitoli “impressi nel video”, NON tagliarli.
Errore comune: croppare troppo e tagliare contenuto o sottotitoli.

7.2 Trim (tagli)

  • Taglia intro/finale o parti indesiderate.
  • Controlla sempre i punti di taglio con preview.

7.3 Regolazione colore

  • Corregge video troppo scuro/slavato.
  • Fallo a piccoli passi e controlla scene giorno/notte.

7.4 Aspetto / Aspect ratio

Regola “da dummy” che salva la vita: se non sai cosa stai forzando, non forzare aspect.
Fai crop corretto + preview filtrata e verifica che non ci siano deformazioni.

8. Modulo Audio

Il modulo audio serve per selezionare tracce, impostare codec/bitrate/canali e applicare miglioramenti (se disponibili nel tuo setup).

8.1 Problema tipico: “Sento rumori ma non i dialoghi”

Causa frequente: downmix errato (il canale centrale con i dialoghi non viene miscelato bene).
Soluzione semplice: prova un profilo downmix diverso e testa su una scena parlata.
Consiglio pratico: prima di convertire un film intero, fai sempre una prova breve su 1–2 minuti con dialoghi evidenti.

9. Sottotitoli (interni / esterni / da DVD)

9.1 Sottotitoli “interni” (dentro MKV/MP4)

  • Se il file li contiene, puoi selezionare lo stream desiderato.
  • Se non li vedi, spesso il file non li ha davvero (o sono in un formato non supportato dal tuo flusso).

9.2 Sottotitoli “esterni” (SRT)

  • Un file .srt è un testo: è leggero e compatibile con quasi tutti i player.
  • Se hai più lingue, rinomina bene o scegli dal modulo sottotitoli.

9.3 Sottotitoli da DVD (VobSub → SRT)

Nei DVD spesso i sottotitoli sono “immagini” (VobSub), non testo. Per avere un SRT leggibile serve OCR (automatico o assistito con Subtitle Edit).

10. Capitoli

Se la sorgente ha capitoli (DVD o file), puoi includerli nell’output. Se un formato non è compatibile, potrebbe essere necessaria una conversione in formato FFmpeg-friendly (dipende dal setup).

11. Gestione Coda (Batch)

  • Salva coda: salva lavori senza eseguirli.
  • Gestisci coda: modifica/riordina.
  • Elabora coda: esegue i job in sequenza.
Consiglio: prima prova su un file singolo, poi vai di batch (serie TV, più episodi, ecc.).

12. LDVD Ripper (DVD → file locale + SRT + handoff)

Scopo: rippare una volta sola dal DVD e lavorare poi su file locali (più veloci, più stabili, riusabili).

12.1 Flusso semplice e consigliato

  1. Apri DVD Ripper.
  2. Seleziona il DVD o la cartella VIDEO_TS.
  3. Aggiungi in coda i file necessari (VTS + IFO associato).
  4. Premi Estrai e attendi la fine.
  5. (Opzionale) Premi OCR SRT per ottenere sottotitoli in testo.
  6. Se OCR fallisce: vai alla sezione Subtitle Edit (fallback).
  7. Premi Passa a HEVC per caricare il risultato nel converter.
Nota: alcuni DVD hanno più titoli/stream. Se i sottotitoli OCR “non escono”, spesso è perché non è stato scelto il titolo/stream corretto.

13. Subtitle Edit (fallback quando OCR fallisce)

Se l’OCR automatico non produce un SRT decente (o non produce nulla), puoi usare Subtitle Edit per estrarre e convertire i sottotitoli dal DVD (VobSub) in modo più guidato.

Quando conviene usare Subtitle Edit?
  • OCR automatico produce SRT vuoto o con caratteri “spazzatura”.
  • Il DVD ha sottotitoli speciali (forced/SDH) o font difficili.
  • Vuoi fare correzioni veloci (accenti, nomi) prima del mux finale.

13.1 Flusso “semplice” (consigliato ai meno esperti)

  1. Apri LDVD Ripper e completa Estrai (così lavori su file locali).
  2. Apri Subtitle Edit.
  3. Apri i sottotitoli dal DVD/file estratto:
    • Tipicamente: File → Open e selezioni il contenuto VobSub (.idx/.sub) se presente, oppure apri direttamente il contenuto del DVD se Subtitle Edit lo supporta.
  4. Se vedi i sottotitoli (anche come immagini), fai OCR guidato:
    • Scegli la lingua corretta (es. Italian).
    • Fai “Recognize / OCR” e correggi le parole sbagliate quando te lo chiede.
  5. Salva come SRT.
  6. Torna in HEVC e includi il file SRT salvato nell’output.
Consiglio da “dummy”: se Subtitle Edit ti propone tante opzioni, fai così:
  • imposta lingua giusta,
  • scegli SRT come output,
  • non toccare altro finché non funziona.

13.2 Se Subtitle Edit non vede i sottotitoli

  • Verifica di aver scelto il titolo/segmento corretto del DVD (VTS giusto).
  • Prova ad aprire un altro file/IFO del film (spesso quello giusto è VTS_01_0.IFO, ma non sempre).
  • Se l’OCR è “pessimo”, prova a cambiare lingua OCR o migliorare contrasto/zoom (dentro Subtitle Edit).

14. Problemi comuni (soluzioni rapide)

14.1 “Non vedo le icone / pulsanti vuoti”

Causa: risorse Qt non compilate (manca icons_rc.py) oppure path errati.
Soluzione: usa il pacchetto .deb (consigliato) oppure rigenera le risorse nel tuo ambiente di sviluppo.

14.2 “FFmpeg non trovato”

Verifica: 
ffmpeg -version
ffprobe -version
Se non funzionano, installa FFmpeg o aggiungilo al PATH.

14.3 “Crop deforma l’immagine”

Controlla forzature aspect. Se non sei sicuro, disattiva forzature e usa crop + preview filtrata.

14.4 “Audio senza dialoghi dopo downmix”

Cambia profilo downmix / traccia audio e prova su una scena parlata.

14.5 “Riavvia…” per ripartire pulito

Menù File → Riavvia… = reset completo dello stato in RAM, come chiudere e riaprire l’app.

1. Introduction

HEVC-Video Converter is an open-source GUI that helps you encode videos to HEVC (H.265) without having to manually type long FFmpeg commands. It also includes advanced tools (preview, filters, audio, subtitles, chapters, queue/batch).

The idea is simple: the app hides the complexity, but keeps the important controls available to you: quality, preset, audio tracks, subtitles/chapters, and a safe “check-before-encode” workflow.

Main highlights (current version):
  • Icon-only toolbar (buttons are PNG icons, LDVD-style).
  • File → Restart… menu entry to restart the app cleanly (RAM state reset).
  • Integrated LDVD Ripper: DVD → local files + (optional) subtitle OCR to SRT + handoff to HEVC.
  • Qt resources use :/icons/... (generated during .deb packaging).
Disclaimer: software is provided “as-is”, without any warranty. Users are responsible for local copyright/codec compliance.

5. How to Encode (step-by-step)

5.1 Open a file

  1. Click Open (toolbar icon) and select your video.
  2. Do a Preview first to confirm it’s the right file.

5.2 Choose quality and preset

  • New users: use CRF and a medium/slow preset.
  • Don’t change 10 things at once: change one setting, then test with filtered preview.

5.3 If you use tools (crop/trim/color): Filtered Preview

Life-saving rule: after any tool (Crop/Trim/Color/Aspect), run Filtered Preview. This is how you catch distortions or wrong cuts before encoding a full movie.

5.4 Convert

  1. Click Convert.
  2. Wait for completion and verify the output.
Zero-surprise method: do a 60–120 second test (short trim) first, then encode the full file.

6. Ready-made recipes (quick results)

6.1 “My video has black bars”

  1. Open the video.
  2. Use Crop to remove only the black bars.
  3. Run Filtered Preview.
  4. Convert.

6.2 “I want to cut intro/outro”

  1. Open Trim.
  2. Set start/end and keep a small safety margin.
  3. Filtered Preview, then Convert.

6.3 “5.1 audio: I hear sounds but no dialog”

  1. Open the Audio module.
  2. Change downmix profile / audio track.
  3. Test on 1–2 minutes with clear dialog.

6.4 “I have a DVD and want SRT subtitles”

  1. Use LDVD Ripper to extract the DVD to local files.
  2. Try OCR SRT.
  3. If OCR fails, use Subtitle Edit (see dedicated section).
  4. Handoff to HEVC and convert.

7. Subtitles (embedded / external / from DVD)

7.1 Embedded subtitles

  • If your file contains subtitle streams (common in MKV), select the one you want.
  • If you don’t see any, the file might not actually contain subtitles.

7.2 External subtitles (SRT)

  • SRT is plain text and widely compatible.
  • Keep filenames clear when you have multiple languages.

7.3 DVD subtitles (VobSub → SRT)

DVD subtitles are often image-based (VobSub). To get SRT text you need OCR: automatic OCR or assisted OCR using Subtitle Edit.

8. LDVD Ripper (DVD → local files + OCR + handoff)

Goal: rip only once from the physical disc, then work on fast local files.

  1. Open DVD Ripper.
  2. Select the DVD / VIDEO_TS.
  3. Queue the needed files (VTS + matching IFO).
  4. Click Extract and wait.
  5. (Optional) Click OCR SRT.
  6. If OCR fails, use Subtitle Edit (next section).
  7. Click Handoff to HEVC.
Many DVDs have multiple titles/streams. Wrong title/IFO selection is a common reason for missing subtitles.

9. Subtitle Edit (fallback when OCR fails)

If automatic OCR produces an empty/broken SRT (or no SRT at all), use Subtitle Edit as a guided fallback. It can open DVD subtitle sources and run assisted OCR, where you can correct mistakes while converting to SRT.

When should you use Subtitle Edit?
  • Automatic OCR creates an empty SRT, garbage characters, or unreadable text.
  • Subtitles are “forced/SDH” or use difficult fonts.
  • You want to quickly fix accents, names, and common OCR errors before muxing.

9.1 Beginner-friendly workflow

  1. Use LDVD Ripper to Extract first (work on local files).
  2. Open Subtitle Edit.
  3. Open the DVD subtitle source:
    • Typically you open a VobSub pair (.idx/.sub) if available, or open from DVD structure if supported.
  4. If you see the subtitles (as images), run OCR:
    • Select the correct OCR language (e.g. Italian).
    • Run “Recognize / OCR” and confirm/correct prompts.
  5. Save as SRT.
  6. Back in HEVC, include the saved SRT in your final output.
Beginner tip: if Subtitle Edit shows many options, do only this first: set the right language, choose SRT output, and don’t tweak advanced settings until it works.

9.2 If Subtitle Edit cannot find subtitles

  • Try a different DVD title/VTS/IFO (common on multi-title DVDs).
  • Check you are opening the correct movie segment, not extras/menus.
  • If OCR is poor, try changing language or improving contrast/zoom inside Subtitle Edit.
